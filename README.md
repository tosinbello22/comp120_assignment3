## About this project

This repository is used to practise version control on GitHub. It holds a small
to-do list program, `task_manager.py`, written in Python. Work is tracked with
the milestone **Tosin Bello_v1.0 Release** and three issues.

## Basic usage instructions

1. Make sure Python 3 is installed. Check by typing `python3 --version` in a terminal.
2. Download or clone this repository:
   `git clone https://github.com/tosinbello22/comp120_assignment3.git`
3. Move into the project folder: `cd comp120_assignment3`
4. Run the program: `python3 task_manager.py`
5. Choose an option from the menu:
   - **1. Add a task** - type the task and press Enter. Empty tasks are not allowed.
   - **2. View tasks** - shows every task with a number and the total count.
   - **3. Quit** - closes the program.

Note: tasks are kept in a list while the program runs, so they are cleared when you quit.
